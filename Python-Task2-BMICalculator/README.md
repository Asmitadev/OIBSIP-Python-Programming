# BMI Calculator – OIBSIP Task 2

## About the Project
A Python GUI application that calculates Body Mass Index (BMI) based on a user's height and weight.

## Features
- Calculate BMI using height and weight.
- Display the BMI result and category.
- Save BMI records locally.
- View previous BMI records and history.
- Track BMI trends.

## Technologies Used
- Python
- Tkinter
- SQLite
- Matplotlib

## How to Run
1. Install Python.
2. Make sure Tkinter and Matplotlib are available.
3. Open the project folder in VS Code.
4. Run `bmi_calculator.py`.
