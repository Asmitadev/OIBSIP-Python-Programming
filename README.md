## 📌 Task 2 – BMI Calculator

The **BMI Calculator** is a GUI-based application developed using **Python and Tkinter**.

The application allows the user to enter their name, weight, and height. It calculates the Body Mass Index (BMI), displays the BMI category, and allows the user to save and view previous records.

### ✨ Features

- Enter user's name
- Enter weight in kilograms
- Enter height in centimeters
- Calculate BMI
- Display BMI value
- Display BMI category
- Save BMI records
- View BMI history
- Clear input fields
- SQLite database integration
- Simple and user-friendly GUI

## ▶️ How to Run

1. Open the `Python-Task2-BMICalculator` folder.
2. Make sure Python is installed on your system.
3. Run the following command:

python bmi_calculator.py

4. The BMI Calculator window will open.
5. Enter the required details and calculate the BMI.

The SQLite database is created automatically when the application is run.
