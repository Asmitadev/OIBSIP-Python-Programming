# Random Password Generator – OIBSIP Task 3

## About the Project
A Python GUI application that generates random passwords with customizable length and character options.

## Features
- Generate passwords of a chosen length.
- Include uppercase letters, lowercase letters, numbers, and symbols.
- Copy generated passwords to the clipboard.
- Check password strength.
- View recently generated passwords.

## Technologies Used
- Python
- Tkinter
- Secrets
- Pyperclip

## How to Run
1. Install Python.
2. Install Pyperclip using `pip install pyperclip`.
3. Open the project folder in VS Code.
4. Run `password_generator.py`.
